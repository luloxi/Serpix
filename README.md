# Serpix

Aplicación personal de gestión profesional para Argentina.

## Objetivo

Una PWA simple para centralizar relaciones comerciales, trabajo, finanzas y facturación simulada. Prioriza una UX clara, rápida y mobile-first; no busca convertirse en un ERP.

## Módulos

- **Inicio:** resumen accionable del día, tareas, seguimientos y cobros.
- **CRM:** personas y organizaciones con relaciones múltiples (cliente, socio, proveedor) y clasificación comercial independiente (potencial / no potencial).
- **Trabajo:** proyectos y tareas vinculados a contactos.
- **Finanzas:** ingresos, egresos, cuentas y saldos en ARS y USD.
- **Facturación:** flujo simulado preparado conceptualmente para una futura integración con ARCA.

## Principios

- Uso personal inicialmente; evitar complejidad y costos innecesarios.
- Mobile-first, accesible y rápido.
- No duplicar contactos por tener más de un tipo de relación.
- No exponer secretos ni credenciales en el cliente.
- Las funciones deben resolver una necesidad concreta.
